# Frontend SAFEHER

Site statique à déployer sur Vercel. Pages : `/`, `/a-propos`, `/actions`, `/ressources`, `/contact`, `/confidentialite`, `/admin`.

Avant le déploiement, remplacez `API_BASE` dans `assets/app.js` et `assets/admin.js` par l'URL réelle du backend PythonAnywhere. Le frontend ne doit contenir aucun mot de passe ou secret administrateur.
